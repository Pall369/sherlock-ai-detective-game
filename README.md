# Sherlock AI — Mystery Detective

A beginner-friendly fictional detective game built with Python and Streamlit.

## Features
- Two fictional mystery cases
- Evidence collection
- Scripted suspect interrogation
- A number-to-letter secret code puzzle
- Detective reasoning board
- Final accusation and score
- No paid API or API key required

## Run locally
```bash
pip install -r requirements.txt
streamlit run app.py
```

## Run from Google Colab
1. Create a new Colab notebook.
2. Install Streamlit: `!pip -q install streamlit`
3. Create `app.py` and paste the contents of the provided `app.py` file.
4. Start Streamlit using a tunnel service you trust, or download the files and run them locally.
5. Do not put private API keys in a public notebook.

This is a fictional game prototype. It uses scripted cases and is not an actual crime investigation or AI-powered inference system.
